This repository holds the source code for the website of a half-day lab at AAAI 2027. If you are looking for the lab itself, go to the website:

**<https://aaai27.pathfinding.ai>**

## About the lab

Multi-agent path finding (MAPF) is the problem of moving a fleet of agents through shared space without them getting in each other's way. In this lab you run experiments with the League of Robot Runners [Start-Kit](https://github.com/MAPF-Competition/Start-Kit) and [PlanViz](https://github.com/MAPF-Competition/PlanViz), alternating between short talks and guided exercises. The sessions cover MAPF foundations and lifelong planning, robot motion models, task scheduling, and execution uncertainty. You do not need prior MAPF experience.
